> **Alcance del documento**  
> Los resultados, porcentajes, nombres de organizaciones y planes incluidos son completamente sintéticos. Su finalidad es mostrar cómo debería estructurarse y visualizarse un reporte de Colmena. No representan una evaluación real ni deben usarse para decisiones laborales.

## Presentación

Esta guía transforma las reglas metodológicas del CENSOPAS-COPSOQ en una propuesta concreta de reporte automático. El documento combina lineamientos generales con dos informes modelo. El primero corresponde a un centro laboral pequeño con 20 casos y utiliza la versión corta. El segundo corresponde a una organización de 200 trabajadores convocados, con 180 registros válidos, y utiliza la versión media. Aunque suele denominarse versión larga en el lenguaje cotidiano, la denominación técnica del instrumento peruano revisado es versión media.

Los ejemplos parten de distribuciones sintéticas ya clasificadas en favorable, intermedia y desfavorable. No se aplican puntos de corte inventados ni se pretende reproducir el motor oficial. Cuando Colmena disponga de baremos autorizados y pruebas de concordancia, las mismas plantillas podrán alimentarse con resultados reales.

## 1. Finalidad y principios del reporte

El reporte final debe convertir las respuestas anónimas en información colectiva útil para prevenir riesgos en su origen. Su función no es calificar personas, producir diagnósticos clínicos, ordenar trabajadores ni atribuir responsabilidades individuales. Debe mostrar la magnitud, localización y prioridad de las exposiciones, complementar la lectura cuantitativa con el análisis del Grupo de Trabajo y conducir a medidas verificables.

| Principio | Aplicación en el reporte |
| --- | --- |
| Finalidad preventiva | Cada hallazgo relevante debe conducir a una pregunta sobre su origen y a una medida sobre la<br>organización del trabajo. |
| Anonimato | No se muestran nombres, identificadores ni celdas con menos de cinco personas. |
| Trazabilidad | Se informa versión del instrumento, baremo, algoritmo, fecha, denominadores y exclusiones. |
| Participación | El Grupo de Trabajo interpreta resultados, identifica causas y acuerda prioridades. |
| No causalidad | Se describen exposiciones y asociaciones; no se afirma que un resultado individual sea causado por una<br>dimensión. |
| Comparabilidad responsable | Las comparaciones usan la misma versión y baremo; no se mezclan resultados corta y media. |
| Accesibilidad | Los colores siempre se acompañan de texto, porcentajes y etiquetas. |
| Regla central<br>El reporte debe evaluar condiciones de trabajo, no trabajadores. Cualquier pantalla o exportación que permita<br>identificar a una persona contradice el propósito colectivo del método. |  |

## 3. Reglas estadísticas y de privacidad

| Regla | Cómo debe verse en el reporte |
| --- | --- |
| Denominador visible | Cada tabla indica N total y n válido. Si el denominador cambia, se explica. |
| Frecuencia y porcentaje | Mostrar n y % juntos. El porcentaje aislado puede ocultar grupos pequeños. |
| Redondeo | Usar un decimal cuando aporte precisión. Aclarar que los totales pueden variar por redondeo. |
| Datos faltantes | Informar faltantes y exclusiones. No imputar silenciosamente. |
| Celdas pequeñas | Suprimir o agrupar resultados con n menor de 5. Revisar cruces que permitan reidentificación. |
| Colores | Verde = favorable, amarillo = intermedio, rojo = desfavorable. Añadir etiquetas y valores. |
| Clasificación final | Riesgo alto si rojo alcanza 50%; factor protector si verde alcanza 50%; riesgo medio si predomina<br>amarillo; empates se documentan con prioridad preventiva. |
| Orden | En la sección de prioridad, ordenar de mayor a menor porcentaje rojo. En anexos, conservar el orden<br>oficial. |
| Comparaciones | No afirmar diferencias sin tamaño suficiente. Las comparaciones descriptivas no son pruebas de<br>significación. |
| Series temporales | Sólo comparar mediciones con versión, baremo, población y unidades equivalentes. |
| Salud | Presentar como información descriptiva y no como diagnóstico o incapacidad. |

### 3.1 Tratamiento de unidades pequeñas

Cuando una unidad tenga entre una y cuatro personas, Colmena debe ocultar la celda y proponer una agrupación aprobada por el Grupo de Trabajo. La supresión debe aplicarse también cuando el total de una fila o columna permita deducir el valor oculto. En organizaciones pequeñas, el reporte puede limitarse al resultado global y evitar comparaciones internas.

## 4. Selección de tablas y gráficos

| Necesidad | Visual recomendado | Evitar |
| --- | --- | --- |
| Composición verde, amarilla y roja | Barras horizontales apiladas al 100% con porcentajes internos. | Pasteles múltiples o gráficos 3D. |
| Prioridades | Barras horizontales ordenadas por porcentaje rojo y línea de<br>referencia de 50%. | Radar, porque dificulta comparar<br>magnitudes. |
| Resultados exactos | Tabla con n, %, nivel y nota interpretativa. | Mostrar sólo el color. |
| Áreas o puestos | Barras agrupadas o tabla de calor, siempre con n de la unidad. | Rankings sin contexto de tamaño. |
| Veinte subdimensiones | Barras apiladas largas, tabla compacta o mapa de calor. | Veinte gráficos separados. |
| Cambio entre mediciones | Línea temporal o puntos conectados para el mismo indicador. | Comparar versiones o baremos<br>distintos. |
| Plan de acción | Tabla de responsables, plazos, indicadores y estado. | Texto general sin responsables. |
| Diseño accesible<br>El color nunca debe ser el único código. Cada barra debe incluir etiqueta, porcentaje o leyenda textual. La<br>versión impresa en escala de grises debe seguir siendo comprensible. |  |  |

## 5. Regla de interpretación narrativa

Cada interpretación debe responder cinco preguntas: qué muestra el resultado, qué nivel alcanza, dónde se concentra, qué posible origen debe investigarse y qué acción preventiva corresponde. La redacción será descriptiva y prudente. No se debe confundir una mayor proporción de respuestas desfavorables con una enfermedad ni atribuir la causa a las características personales de los trabajadores.

| Componente | Pregunta guía | Ejemplo de redacción |
| --- | --- | --- |
| Hallazgo | ¿Cuál es la distribución? | El 60% se ubicó en situación desfavorable. |
| Nivel | ¿Qué clasificación corresponde? | La dimensión se clasificó como riesgo alto. |
| Localización | ¿En qué unidad destaca? | La mayor proporción roja se observó en Producción y Logística. |
| Origen | ¿Qué debe contrastarse? | El Grupo de Trabajo deberá revisar cargas, plazos y dotación. |

| Componente | Pregunta guía | Ejemplo de redacción |

| Acción | ¿Qué medida organizacional procede? | Se propone revisar la planificación y redistribución de tareas. |
| Límite | ¿Qué no puede concluirse? | El resultado no identifica personas ni demuestra causalidad. |

Modelo integrado: La dimensión Exigencias psicológicas mostró 60% de respuestas desfavorables y se clasificó como riesgo alto. El resultado indica una prioridad preventiva colectiva. El Grupo de Trabajo deberá contrastar si la acumulación de tareas, los plazos, la dotación o las interrupciones explican la exposición y acordar medidas sobre la organización del trabajo. Esta distribución no permite diagnosticar a trabajadores ni establecer causalidad individual.

## 6. Control de calidad antes de emitir el PDF

| Control | Condición de aprobación |
| --- | --- |
| Instrumento | Versión, edición y baremo identificados. |
| Población | Convocados, participantes, válidos y excluidos conciliados. |
| Cálculo | Conteos y porcentajes coinciden; las categorías suman el n válido. |
| Clasificación | Reglas de 50% y empates aplicadas de manera reproducible. |
| Privacidad | No hay identificadores ni celdas menores de cinco. |
| Visuales | Leyendas, unidades, denominadores, notas y colores accesibles. |
| Narrativa | Sin causalidad, diagnóstico, estigmatización ni afirmaciones individuales. |
| Plan | Cada prioridad tiene medida, responsable, plazo e indicador. |
| Trazabilidad | El reporte conserva versión de datos, algoritmo, fecha y hash. |
| Aprobación | El Grupo de Trabajo revisó y documentó acuerdos y discrepancias. |

## 8. Reporte ilustrativo de la versión media

> **Datos sintéticos**  
> Organización ficticia: Industrias del Sur S.A. Código del estudio: SYN-M200-2026. Se simularon 200 trabajadores convocados, 186 respuestas y 180 registros válidos. Las categorías de riesgo son ilustrativas.

### 8.13 Conclusiones del ejemplo medio

- Las exigencias psicológicas constituyen el principal riesgo dimensional y requieren intervención directa sobre carga, ritmo y planificación.

- La versión media revela prioridades que quedarían ocultas en un resultado sólo dimensional, especialmente calidad de liderazgo, conflicto de rol e inseguridad sobre el empleo.

- Producción, Comercial y Logística concentran la mayor proporción desfavorable de exigencias psicológicas en el ejemplo.

- El control sobre el trabajo y el capital social deben mantenerse como factores protectores durante los cambios.

- La evaluación siguiente debe conservar versión, baremo y unidades comparables y acompañarse del seguimiento de indicadores del plan.
